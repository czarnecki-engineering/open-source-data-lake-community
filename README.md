# Open Source Data Lake Community

This repository is the Community edition of the Open Source Data Lake project.

It provides a local reference runtime built around Docker Compose, MinIO, Apache Airflow, Jupyter, and lightweight application components. The repository also includes example overlays that demonstrate how additive capabilities can be packaged, installed, and validated without changing the canonical overlay contract.

Key documentation:
- Overlay contract: `docs/architecture/overlay_contract_v1.md`
- Overlay development and usage guide: `docs/HOWTO_OVERLAYS.md`
- Repository operations: `RUNBOOK.md`
