# Open Source Data Lake Community

## What this is

This repository is the Community edition of Open Source Data Lake. It provides a local reference runtime for building and validating filesystem-based overlays on top of the base Docker Compose stack.

It solves the problem of developing and exercising additive data-lake capabilities locally before packaging and installing them into a compatible Open Data Lake environment.

## What this is NOT

This README does not define overlay contract rules; use the contract document for rules and validation requirements.

This README does not replace the runbook; use the runbook for starting, stopping, and operating the runtime.

## Start here

1. Read [HOWTO_OVERLAYS.md](docs/HOWTO_OVERLAYS.md) -> build and use overlays
2. Use [RUNBOOK.md](RUNBOOK.md) -> run the system
3. Refer to [overlay_contract_v1.md](docs/architecture/overlay_contract_v1.md) -> rules and validation
